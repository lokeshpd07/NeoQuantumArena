# NeoQuantum Arena

Interactive quantum learning, visual circuit simulation, and real-time multiplayer PvP quantum arena.

## Features

- **Visual Quantum Lab**: Interactive drag-and-drop circuit builder with multi-qubit simulation, Dirac notation, statevector & Bloch sphere visualization, and OpenQASM 2.0 export.
- **PvP Quantum Battle**: Real-time matchmaking and circuit building duels against opponents.
- **Arena Challenges**: Multi-tier quantum algorithmic puzzles with progressive hints.
- **Interactive Learn Modules**: Step-by-step quantum computing curriculum with immediate quiz feedback.
- **Global Leaderboards**: Competitive player rankings across Global, Teams, and Campus brackets.
- **Persistent Profile & Dashboard**: XP progression, level milestones, streaks, daily quests, and achievements.

## Development

```sh
npm install
npm run dev
```

Built with **TanStack Start**, **React**, **TypeScript**, and **Tailwind CSS**.
